# 截图与演示素材

根目录 `README.md` 里已经留好了「界面预览」的注释块，图片放齐后取消注释即可。

## 需要 6 张

| 文件名 | 页面 | 要求 |
|---|---|---|
| `learning.png` | 学习路线（`/learning`） | 有阶段进度，最好能看到已完成的题目 |
| `problems.png` | 题库列表（`/problems`） | 有多种题型（OJ / 客观 / 简答） |
| `judge.png` | 提交记录或判题结果 | 能看到 AC / 非 AC 状态与耗时 |
| `battle.png` | 1v1 对战（`/battle`） | 房间进行中，两个账号 |
| `leaderboard.png` | 榜单（`/leaderboard`） | 有真实排名数据 |
| `admin.png` | 运营后台 | 题目或造数据任务管理页 |

## 怎么截

- 浏览器窗口 1600×1000 左右，缩放 100%，**隐藏书签栏**。
- 用测试账号：不要露出真实手机号、邮箱、`deploy/.env` 里的密钥。
- 统一主题（全用明亮或全用暗淡），6 张摆在一起才像同一个产品。
- 图片放本目录，文件名与上表一致，根 README 的注释块才能直接生效。

## 可选

- `battle.gif`：一段 10–15 秒的对战录屏，比静态图更有说服力。
- 2 分钟演示视频：判题 → 对战 → 榜单 → 后台，上传后把链接加到 README 顶部。
