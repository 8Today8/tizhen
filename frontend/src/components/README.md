# 组件

按通用性与业务域组织。组件只负责展示与交互，不直接发起 HTTP 请求；数据由页面或组合式函数注入。

| 目录 | 职责 |
|---|---|
| `base/` | 头像上传等跨业务通用组件 |
| `profile/` | 个人中心面板：头像、CF 绑定、LLM 凭证、手动申报 |
| `problem/` | 题面渲染、代码编辑器、判题结果 |
| `battle/` | 房间信息、倒计时、双方状态 |
| `datagen/` | 模式选择、数据范围、任务状态 |
| `leaderboard/` | 榜单表格、我的排名、外部成绩申报 |
| `admin/` | 后台页面、表格、工具栏、分页与空状态组件 |

组件只负责展示与交互，通过 props/emits 与页面通信；数据请求由页面或组合式函数负责。
